# FitFuel — Fitness & Nutrition App

FitFuel is a fitness and nutrition web application in development, designed to help users organize their workouts, track progress, and manage nutrition in one place.

The project is an opportunity to turn a product idea into a working application through iterative development, feature planning, and AI-assisted coding.

## Features

* **User onboarding:** Collect fitness goals, activity levels, and dietary preferences.
* **Dashboard:** A central place to access fitness and nutrition features.
* **Workouts:** Browse workout information and access individual workout pages.
* **Nutrition:** A dedicated area for nutrition-related features.
* **Progress tracking:** A page for reviewing fitness progress.
* **Authentication:** Login flow and Supabase integration.
* **Coach API:** An API route for coach-related functionality.

*Note: The application is a work in progress. Feature completeness and functionality may vary during development.*

## Tech Stack

* Next.js
* React
* TypeScript
* Supabase
* JavaScript/TypeScript tooling and npm

## Development Approach

I use AI-assisted development tools, including Cursor, to help implement features, troubleshoot issues, and iterate on the application. My approach combines product thinking, breaking requirements into manageable tasks, testing changes, and refining the user experience.

## Running Locally

1. Clone the repository.

2. Install dependencies:

   ```bash
   npm install
   ```

3. Configure the required Supabase environment variables in a local `.env.local` file.

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open http://localhost:3000.
